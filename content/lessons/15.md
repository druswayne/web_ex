## Теория к занятию

### Мини-тема 1. Область определения и множество значений

Смотри, функция связывает каждое допустимое значение аргумента $x$ с единственным значением $y$. Но не всякое число обязательно допустимо. Например, на ноль делить нельзя, а подкоренное выражение должно быть неотрицательным.

**Область определения** — все значения аргумента, при которых формула функции имеет смысл.

**Множество значений** — все значения функции, которые получаются при аргументах из области определения.

Область определения обычно обозначают $D(f)$, а множество значений — $E(f)$.

#### Определение и формулы

Если функция задана формулой $y=f(x)$, то:

$$D(f)=\{x:\ f(x)\text{ имеет смысл}\}.$$

Для дроби:

$$\frac{A(x)}{B(x)}\quad B(x)\ne0.$$

Для квадратного корня:

$$\sqrt{A(x)}\quad A(x)\ge0.$$

Если есть и корень, и знаменатель, выполняются оба условия одновременно.

#### Правила

- знаменатель не равен нулю;
- выражение под знаком квадратного корня неотрицательно;
- ограничения пересекаются;
- множество значений находят по графику, формуле или преобразованию;
- концы промежутка включаются только при наличии квадратной скобки.

#### Алгоритм

1. Выписать все ограничения.
2. Решить каждое условие.
3. Найти пересечение полученных промежутков.
4. Записать область определения.
5. Для множества значений исследовать формулу или график.

#### Мини-пример

Найдите область определения функции

$$y=\frac{\sqrt{5-x}}{x+2}.$$

*Решение:*

Дано:

$$y=\frac{\sqrt{5-x}}{x+2}.$$

Найти: $D(f)$.

Подкоренное выражение должно быть неотрицательным:

$$5-x\ge0.$$

Переносим $5$ в правую часть:

$$-x\ge-5.$$

При делении на отрицательное число знак меняется:

$$x\le5.$$

Знаменатель не должен обращаться в ноль:

$$x+2\ne0.$$

Следовательно,

$$x\ne-2.$$

Пересекаем условия $x\le5$ и $x\ne-2$:

$$D(f)=(-\infty;-2)\cup(-2;5].$$

Проверка: при $x=5$ корень равен нулю, поэтому $5$ входит в область определения; при $x=-2$ знаменатель равен нулю, поэтому это значение исключается.

**Ответ:** $(-\infty;-2)\cup(-2;5]$.

#### Ловушки экзамена

- забыть исключить нуль знаменателя;
- поставить условие $5-x>0$ вместо $5-x\ge0$;
- объединить промежутки вместо пересечения;
- включить запрещённую точку в ответ.

### Мини-тема 2. Монотонность, нули, наибольшее и наименьшее значения

График функции можно читать как маршрут: если при движении слева направо график поднимается, функция возрастает; если опускается — убывает.

**Нуль функции** — значение аргумента, при котором значение функции равно нулю.

Функция возрастает на промежутке, если большему аргументу соответствует большее значение функции. Функция убывает, если большему аргументу соответствует меньшее значение.

#### Формулы

Нули функции находят из уравнения

$$f(x)=0.$$

Наибольшее значение — самое большое значение $y$ на рассматриваемом промежутке.

Наименьшее значение — самое маленькое значение $y$ на рассматриваемом промежутке.

Для квадратичной функции

$$y=a(x-m)^2+n$$

вершина параболы имеет координаты

$$(m;n).$$

Если $a>0$, то $n$ — наименьшее значение функции.

Если $a<0$, то $n$ — наибольшее значение функции.

#### Правила

- нули ищут по оси абсцисс;
- промежутки знакопостоянства записывают по значениям $x$;
- направление ветвей параболы зависит от знака $a$;
- значение функции и значение аргумента — разные величины;
- на конечном промежутке проверяют также концы.

#### Алгоритм

1. Найти нули из уравнения $f(x)=0$.
2. Определить знак функции на промежутках.
3. По формуле или графику определить возрастание и убывание.
4. Найти вершину, если функция квадратичная.
5. Сравнить значения на нужном промежутке.

#### Мини-пример

Найдите нули и наименьшее значение функции

$$y=x^2-4x+7.$$

*Решение:*

Дано:

$$y=x^2-4x+7.$$

Найти: нули и наименьшее значение.

Выделим полный квадрат:

$$y=x^2-4x+4+3.$$

Получаем:

$$y=(x-2)^2+3.$$

Квадрат любого числа неотрицателен:

$$(x-2)^2\ge0.$$

Следовательно,

$$y\ge3.$$

Наименьшее значение достигается при

$$x-2=0,$$

$$x=2.$$

Наименьшее значение равно

$$y_{\min}=3.$$

Проверим нули:

$$(x-2)^2+3=0.$$

Левая часть всегда не меньше $3$, поэтому решений нет.

**Ответ:** нулей нет; $y_{\min}=3$.

#### Ловушки экзамена

- назвать $x=2$ наименьшим значением вместо $y=3$;
- забыть, что квадрат не может быть отрицательным;
- перепутать возрастание и убывание;
- искать нули только по вершине.

### Мини-тема 3. Чётные и нечётные функции

Чётность — это симметрия графика относительно оси ординат. Если точка $(x;y)$ принадлежит графику чётной функции, то точка $(-x;y)$ тоже принадлежит ему.

Нечётная функция имеет симметрию относительно начала координат: вместе с точкой $(x;y)$ существует точка $(-x;-y)$.

#### Определения и формулы

Функция называется чётной, если её область определения симметрична относительно нуля и

$$f(-x)=f(x).$$

Функция называется нечётной, если область определения симметрична относительно нуля и

$$f(-x)=-f(x).$$

Примеры:

$$f(x)=x^2$$

— чётная функция.

$$f(x)=x^3$$

— нечётная функция.

#### Правила

- сначала проверяют симметричность области определения;
- затем находят $f(-x)$;
- при чётности знак значения не меняется;
- при нечётности знак значения меняется;
- функция с областью определения $[0;+\infty)$ не может быть чётной или нечётной по стандартному определению.

#### Алгоритм проверки

1. Найти область определения.
2. Проверить, что вместе с $x$ в неё входит $-x$.
3. Вычислить $f(-x)$.
4. Сравнить с $f(x)$ и $-f(x)$.
5. Сделать вывод.

#### Мини-пример

Определите, является ли функция

$$f(x)=3x^4-2x^2+1$$

чётной или нечётной.

*Решение:*

Область определения — все действительные числа:

$$D(f)=\mathbb R.$$

Она симметрична относительно нуля.

Найдём $f(-x)$:

$$f(-x)=3(-x)^4-2(-x)^2+1.$$

Так как чётные степени сохраняют значение, получаем:

$$f(-x)=3x^4-2x^2+1.$$

Следовательно,

$$f(-x)=f(x).$$

Функция является чётной.

**Ответ:** функция чётная.

#### Ловушки экзамена

- проверить только формулу и забыть про область определения;
- считать $(-x)^4=-x^4$;
- при нечётности написать $f(-x)=f(x)$;
- перепутать ось ординат и начало координат.

### Мини-тема 4. Сдвиги графиков

Сдвиг графика меняет положение графика, но не его форму. Здесь особенно важно не перепутать знак внутри скобок.

Если график $y=f(x)$ сдвинуть вправо на $a$, получится $y=f(x-a)$. Внутри скобок знак как будто «противоположен направлению».

#### Формулы

Сдвиг вправо на $a$:

$$y=f(x-a).$$

Сдвиг влево на $a$:

$$y=f(x+a).$$

Сдвиг вверх на $b$:

$$y=f(x)+b.$$

Сдвиг вниз на $b$:

$$y=f(x)-b.$$

Если график сдвигают вправо на $a$ и вверх на $b$, то

$$y=f(x-a)+b.$$

#### Правила

- внутри скобок знак противоположен горизонтальному направлению;
- вне скобок знак совпадает с вертикальным направлением;
- нули после сдвига находят из нового уравнения;
- каждая точка $(x_0;y_0)$ при сдвиге вправо на $a$ и вверх на $b$ переходит в $(x_0+a;y_0+b)$.

#### Алгоритм

1. Определить исходный график.
2. Найти направление сдвига по формуле.
3. Перенести несколько характерных точек.
4. Соединить точки сохранённой формой графика.
5. Для нулей решить уравнение новой функции.

#### Мини-пример

График $y=x^2$ сдвинули на $2$ единицы вправо и на $3$ единицы вниз. Запишите формулу новой функции и её вершину.

*Решение:*

Исходная функция:

$$f(x)=x^2.$$

Сдвиг вправо на $2$ единицы означает замену $x$ на $x-2$:

$$y=(x-2)^2.$$

Сдвиг вниз на $3$ единицы означает вычитание $3$:

$$y=(x-2)^2-3.$$

Вершина исходной параболы $(0;0)$.

После сдвига вправо на $2$ и вниз на $3$ она переходит в точку

$$(2;-3).$$

**Ответ:** $y=(x-2)^2-3$; вершина $(2;-3)$.

#### Ловушки экзамена

- записать $f(x+2)$ для сдвига вправо;
- перепутать сдвиг вверх и вниз;
- изменить форму параболы вместо её положения;
- потерять скобки.

## Сводка формул «выучить наизусть»

$$D(f)=\{x:\ f(x)\text{ имеет смысл}\}.$$

$$f(x)=0$$

— уравнение для нахождения нулей.

$$f(-x)=f(x)$$

— условие чётности.

$$f(-x)=-f(x)$$

— условие нечётности.

$$y=f(x-a)$$

— сдвиг вправо на $a$.

$$y=f(x+a)$$

— сдвиг влево на $a$.

$$y=f(x)+b$$

— сдвиг вверх на $b$.

$$y=f(x)-b$$

— сдвиг вниз на $b$.

## Правила, которые нельзя путать

- область определения относится к $x$, множество значений — к $y$;
- нуль функции — это значение $x$, а не значение $y$;
- $f(x-a)$ сдвигает график вправо;
- $f(x+a)$ сдвигает график влево;
- чётная функция симметрична относительно оси ординат;
- нечётная функция симметрична относительно начала координат;
- при делении на ноль знаменатель запрещён;
- подкоренное выражение квадратного корня неотрицательно.

### Р1. Сборник, вариант 15, задание 1

Определите, какое из следующих множеств может быть областью определения чётной функции:

а) $(-7;7]$;

б) $[-9;-1)\cup(-1;9]$;

в) $[-10;10]$;

г) $[-8;-1)\cup(-1;1)\cup(1;8)$;

б) Число $9$ входит, а число $-9$ не входит.

### Р2. Сборник, вариант 5, задание 7

Известно, что график функции $y=f(x)$ симметричен относительно оси ординат, $f(-3)=5$, а $f(2)=-6$. Найдите значение выражения $f(3)+2f(-2)$.

*Решение:*

Симметрия относительно оси ординат означает, что функция чётная:

$$f(-x)=f(x).$$

Поэтому

$$f(3)=f(-3)=5.$$

Также

$$f(-2)=f(2)=-6.$$

Подставляем значения:

$$f(3)+2f(-2)=5+2\cdot(-6).$$

$$5+2\cdot(-6)=5-12=-7.$$

**Ответ:** $-7$.

### Р3. Сборник, вариант 43, задание 7

Найдите область определения функции

$$y=\sqrt{12-6x}-\frac{3}{x^2-4}.$$

*Решение:*

Подкоренное выражение должно быть неотрицательным:

$$12-6x\ge0.$$

$$-6x\ge-12.$$

$$x\le2.$$

Знаменатель не должен быть равен нулю:

$$x^2-4\ne0.$$

Разложим на множители:

$$x^2-4=(x-2)(x+2).$$

Следовательно,

$$x\ne2,\qquad x\ne-2.$$

Пересекаем условия:

$$x\le2,\qquad x\ne2,\qquad x\ne-2.$$

Получаем

$$D(f)=(-\infty;-2)\cup(-2;2).$$

Проверка: точка $2$ исключается из-за знаменателя, точка $-2$ также исключается; при $x<2$ корень определён.

**Ответ:** $(-\infty;-2)\cup(-2;2)$.

### Р4. Сборник, вариант 51, задание 7

Найдите наименьшее целое значение аргумента, принадлежащее области определения функции

$$y=\frac{\sqrt{x+8}}{x^2-2x-80}.$$

*Решение:*

Для корня требуется:

$$x+8\ge0,$$

$$x\ge-8.$$

Знаменатель не должен быть равен нулю:

$$x^2-2x-80\ne0.$$

Разложим квадратный трёхчлен:

$$x^2-2x-80=(x-10)(x+8).$$

Поэтому

$$x\ne10,\qquad x\ne-8.$$

Область определения:

$$D(f)=[-8;+\infty)\setminus\{-8;10\}.$$

То есть

$$D(f)=(-8;10)\cup(10;+\infty).$$

Наименьшее целое число из этого множества — $-7$.

Проверка:

$$-7+8=1\ge0,$$

$$(-7)^2-2(-7)-80=49+14-80=-17\ne0.$$

**Ответ:** $-7$.
